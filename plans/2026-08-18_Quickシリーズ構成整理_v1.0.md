# Quickシリーズ構成整理 計画書 v1.0

作成日: 2026-08-18
対象バージョン: v0.1.0

## 1. 目的・背景

QuickFileCopyをQuickDiskBenchなどと同じQuickシリーズとして保守・配布できる構成へ整理する。

## 2. 現状

C++版が`native/`、UIが`ui-native/`、旧Python版がリポジトリ直下の`src/`と`tests/`に混在し、
READMEも旧FastestCopy中心だった。配布用文書、ライセンス、仕様書が未整備だった。

## 3. 変更方針

- 製品C++コード、UI、旧プロトタイプ、開発文書、配布文書を役割別に分離する。
- EXEへHTMLを埋め込む既存方式を維持する。
- 英語版と日本語版のリポジトリ・配布文書を揃える。
- Gitのコミット、ブランチ、設定、remoteには触れない。

## 4. 変更対象

| 対象 | 変更内容 |
| --- | --- |
| `core/native/` | C++製品コードとテストを集約 |
| `templates/`, `static/` | WebView2開発用UIを配置 |
| `prototype/python/` | 旧Python/PySide6版を保存 |
| `document/`, `plans/` | 開発文書と作業記録を追加 |
| `dist/binary/`, `dist/documents/` | 成果物と配布文書を分離 |
| ルート文書・ビルド | Quickシリーズ規約へ更新 |

## 5. 検証方法

- `build_native.py`によるGUI/CLIビルド
- ネイティブスモークテスト
- CLIヘルプと配布ファイル名の確認
- README、HISTORY、配布文書の日英対応・バージョン・ハッシュ確認

## 6. リスク

- ファイル移設によるビルドパス切れ
- RCのHTML/アイコン参照切れ
- テストが旧成果物名を参照する可能性
