QuickFileCopy - 更新履歴

v1.0.0 (2026-08-22)
- ネイティブ GUI / CLI の初回公開リリース。
- v* タグで GitHub Actions が配布 ZIP を作る。

v0.1.0 (2026-08-18)
- C++ネイティブコピーエンジンとコンパクトなWebView2 GUIを追加。
- 安全な置換、キャンセル、SHA-256検証、自動再開を追加。
- Windowsのセキュリティ情報とファイルシステムメタデータ保持を追加。
- Google DriveなどEA非対応のファイルシステムで通常コピーが失敗する問題を修正。
- 保存先に応じた並列処理とローカル/SMB/クラウド向け経路を追加。
- QDB形式の言語ボタンによる、設定保存付き日本語／English切替を追加。
- Quickシリーズ共通の配布構成へ整理。
